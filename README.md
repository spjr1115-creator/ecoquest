# EcoQuest

Gamified environmental experience designed to encourage sustainable habits through interactive challenges and progress.

## Overview

EcoQuest is an interactive web platform designed to promote sustainability through daily eco-friendly activities. Users can track their environmental actions, complete eco-challenges, and visualize their personal progress toward sustainable living.

## Key Features

- **Daily Eco Challenges**: Interactive tasks focused on waste reduction, energy saving, and sustainable habits.
- **Progress Tracking**: Visual feedback and status tracking for completed environmental activities.
- **Responsive Design**: Fast and mobile-friendly web interface.

## Tech Stack

- **Frontend**: JavaScript, HTML5, CSS3
- **Data Persistence**: Local Storage / Web Storage API
- **Deployment**: Vercel

## Live Demo

- **Live App**: [https://ecoquest-neer4.vercel.app/](https://ecoquest-neer4.vercel.app/)

## Getting Started

```bash

```

Open `index.html` in your browser.
