## 🌍 What is EcoQuest?

**EcoQuest is a gamified sustainability learning platform that turns environmental awareness into meaningful action.**

Traditional environmental education often stops at:

> **Learn → Remember → Forget**

EcoQuest changes that to:

> **Learn → Challenge → Act → Submit Proof → Get Verified → Earn XP → Create Impact**

Students don't just learn about sustainability.

**They practice it.**

---

## ✨ Why EcoQuest?

Environmental education has a simple problem:

### Knowledge doesn't always become behavior.

EcoQuest bridges that gap by combining:

* 📚 **Interactive environmental learning**
* 🎯 **Real-world sustainability challenges**
* 📸 **Proof-based challenge submissions**
* 👨‍🏫 **Teacher verification**
* ⚡ **XP and leveling**
* 🏆 **Badges and achievements**
* 🔥 **Activity streaks**
* 🌍 **Eco-impact scoring**
* 📊 **Personal progress analytics**
* 🏅 **Leaderboards**
* 🎓 **Placement preparation resources**

The result is an ecosystem where **learning sustainability becomes a habit rather than a one-time activity.**

# 📸 Proof-Based Verification

EcoQuest doesn't simply trust a button that says:

> **"I completed the challenge."**

Students can submit evidence for completed challenges.

```text
Student completes challenge
          ↓
     Submit proof
          ↓
    Pending review
          ↓
 Teacher / Admin reviews
          ↓
     ┌────┴────┐
     ↓         ↓
  Approved   Rejected
     ↓
  Rewards
```

This creates accountability and prevents the gamification system from becoming meaningless.

# 🌍 Eco Impact

EcoQuest tracks **Eco Impact Points** to provide a simple gamified representation of environmental contribution.

Instead of reducing sustainability to abstract lessons, users can see their progress through:

```text
Challenges Completed
        +
Learning Progress
        +
Verified Actions
        ↓
   Eco Impact Score
```

> **Note:** Eco Impact Points are a gamification metric and should not be interpreted as a direct scientific measurement of carbon reduction or environmental savings.

# 🗄️ Database Model

The platform is backed by a relational PostgreSQL database.

Core entities include:

```text
users
 │
 ├── user_lessons
 │       │
 │       └── lessons
 │
 └── user_challenges
         │
         └── challenges
```

Additional platform functionality includes:

```text
placement_materials
user_purchases
```

The database also uses **Row Level Security (RLS)** to control access to application data.

---

# 🔐 Security

EcoQuest uses Supabase authentication and PostgreSQL Row Level Security.

Important application-level security concepts include:

* 🔑 Authenticated sessions
* 👥 Role-based access
* 🛡️ Row Level Security
* 🔒 Protected application routes
* ⚙️ Database-side verification logic
* 🚫 Blocked-user handling

The goal is to keep sensitive reward and verification logic on the trusted backend rather than relying entirely on the browser.

# ⚙️ Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/spjr1115-creator/ecoquest.git
cd ecoquest
```

## 2. Install dependencies

```bash
cd apps/web
npm install
```

## 3. Configure Supabase

Create a Supabase project and configure the required environment variables.

Create:

```text
.env
```

Add:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## 4. Configure the database

Run the SQL contained in:

```text
supabase_schema.sql
```

inside your Supabase SQL editor.

## 5. Start the development server

```bash
npm run dev
```

The application will then be available through the local Vite development server.
